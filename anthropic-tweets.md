## Typical topics you'll see in their feeds

- **Research drops** — interpretability circuits, alignment experiments,
  agentic misalignment stress tests, constitutional AI updates.
- **Claude product news** — new model releases (Opus / Sonnet / Haiku),
  Claude Code features, API updates, long-context and tool-use demos.
- **AI policy & safety commentary** — Jack Clark's *Import AI* highlights,
  responses to regulation, RSP (Responsible Scaling Policy) updates.
- **Hiring** — frequent calls for research scientists and research engineers,
  especially on interpretability and alignment teams.
- **Personal takes** — Amanda Askell on AI ethics and model character;
  Chris Olah on visualization and interpretability; Sam Bowman on evals.

## How to see what they are tweeting right now

Because X requires a logged-in session for most programmatic access, the
simplest options are:

1. Open each handle in a browser (links above).
2. Build a public X List that includes all the handles above and subscribe to
   it.
3. Use the official X API with a developer key if you need a machine-readable
   feed.
